# JLPT Exam Study Timetable & Kanji/Kana Learning App (PWA)

A Progressive Web App (PWA) designed for iOS and mobile devices to manage JLPT preparation timetable with alarms, countdowns, and a complete Japanese Kanji and Kana reference dictionary.

## Features
- **Exam Date:** December 9, 2026 (09/12/2026) countdown
- **Timetable & Alarms:** Session countdowns with audio synthesizer alarms
- **Japanese Reference:**
  - 71 Hiragana (Basic + Dakuon)
  - 46 Katakana
  - 114 N5 Kanji (Minna no Nihongo 1)
  - 186 N4 Kanji (Minna no Nihongo 2)
  - 336 N3 Kanji (Nihongo Soumatome N3 6-week curriculum)
  - 780+ Japanese compound vocabulary words with Burmese meanings
- **Audio:** Web Speech API Japanese text-to-speech
- **Offline Mode:** iOS PWA with Service Worker offline caching
